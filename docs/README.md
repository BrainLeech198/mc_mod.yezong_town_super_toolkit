# 项目文档

本目录保存项目的使用说明、开发说明、架构记录和设计/实施过程材料。

## 从这里开始

- [项目结构与运行链路](项目结构.md)：模块职责、启动过程和认证调用路径。
- [代理客户端地址适配](代理IP适配.md)：默认解析、适配器契约和信任边界。
- [文档编写规范](文档规范.md)：文档类型、内容要求、更新和归档规则。
- [版本管理规范](版本管理规范.md)：版本递增、版本来源、发布记录和打包清单。
- [更新记录](../CHANGELOG.md)：正式产物的用户可见变化。
- [部署与迁移](../DEPLOY.md)：服务器部署、SAuth 数据迁移、指令和配置说明。
- [缺陷记录](issues/)：可复现问题、影响、根因、修复范围和验证结果。
- [设计与实施记录](superpowers/)：按日期保存的方案和实施计划；以当前代码和部署文档为准。

## 维护约定

涉及用户可见行为、配置、命令、数据格式或安全边界的代码变更，应在同一变更中更新对应说明。发现问题时先记录复现条件、实际结果、预期结果和影响，再按《文档编写规范》更新问题记录或专题文档。
