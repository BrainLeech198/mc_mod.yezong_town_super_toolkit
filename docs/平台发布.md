## 文件与依赖

同一项目分别上传 Forge、Fabric 文件，每个文件只标记实际加载器和 Minecraft 1.20.1，不勾选 NeoForge、Quilt 或未经验证的游戏版本。

| 文件 | 构建平台 | CurseForge 依赖关系 |
|---|---|---|
| `yzt_super-1.4.0-mc1.20.1-forge.jar` | Forge 47.4.0，运行 Java 17 | 不添加 Fabric 依赖；Forge 使用自身配置系统 |
| `yzt_super-1.4.0-mc1.20.1-fabric.jar` | Fabric Loader 0.20.1，运行 Java 17 | Fabric API、Forge Config API Port 均已设置为 Required Dependency |

Fabric 选用 Fabric API **0.92.12+1.20.1**、Forge Config API Port **8.0.3 的 Fabric 版**。依赖项目分别为 [Fabric API](https://www.curseforge.com/minecraft/mc-mods/fabric-api)（项目 306612）、[Forge Config API Port](https://www.curseforge.com/minecraft/mc-mods/forge-config-api-port)（项目 547434）；不能误选其 Forge/NeoForge 或其他游戏版本文件。精确约束以工具箱 JAR 元数据为准。

此次上传使用 GitHub 已公开的 1.4.0 稳定发行包；本地两个 JAR 的 SHA-256 与 Release 记录一致。1.4.1 仍是候选，未上传到 CurseForge，也不是新的稳定发行。本次重新核对包文件不代表对 1.4.0 最终附件重做全部游戏验收。
