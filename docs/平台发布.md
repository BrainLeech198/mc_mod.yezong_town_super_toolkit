## 平台选择依据

维护者确认主要源码由 AI 生成。[Modrinth Content Rules](https://modrinth.com/legal/rules/) §6 禁止公开发布主要或全部 AI 生成的项目；披露不能代替此准入条件，因此不提交当前版本。

核对的 [CurseForge Moderation Policies](https://support.curseforge.com/support/solutions/articles/9000197279-moderation-policies) 未列出相同的全面禁止条款，并说明了可能误导用户的 AI 展示图披露要求。这仅支持“可尝试投稿”的判断，不保证审核通过。新图标与介绍均如实说明 AI 来源。投稿时重新核对政策；被要求澄清时提供真实开发、构建和验证记录。

## 文件与依赖

同一项目分别上传 Forge、Fabric 文件，每个文件只标记实际加载器和 Minecraft 1.20.1，不勾选 NeoForge、Quilt 或未经验证的游戏版本。

| 文件 | 构建平台 | CurseForge 依赖关系 |
|---|---|---|
| `yzt_super-1.4.1-mc1.20.1-forge.jar` | Forge 47.4.0，运行 Java 17 | 不添加 Fabric 依赖；Forge 使用自身配置系统 |
| `yzt_super-1.4.1-mc1.20.1-fabric.jar` | Fabric Loader 0.20.1，运行 Java 17 | Fabric API、Forge Config API Port 均为 Required Dependency |

Fabric 选用 Fabric API **0.92.12+1.20.1**、Forge Config API Port **8.0.3 的 Fabric 版**。依赖项目分别为 [Fabric API](https://www.curseforge.com/minecraft/mc-mods/fabric-api)（项目 306612）、[Forge Config API Port](https://www.curseforge.com/minecraft/mc-mods/forge-config-api-port)（项目 547434）；不能误选其 Forge/NeoForge 或其他游戏版本文件。精确约束以工具箱 JAR 元数据为准。

正式上传前合并对应候选、确认版本和文件状态、记录源提交与 SHA-256，并通过 [发布规范](发布规范.md) 的构建和内容检查。本候选没有改变游戏逻辑或默认配置；不能把仅元数据检查称为重做全部游戏验收。

## 首次账号操作

1. 所有者本人在 [CurseForge 作者入口](https://authors.curseforge.com/) 注册或登录，完成所需验证并阅读平台条款。无需购买 Pro 来准备普通 Mod 投稿。
2. 在自己的账号下创建项目，使用上面的字段、图标和介绍。创建后提供项目链接或 ID，确认归属正确。
3. 从已通过检查的构建取得两个最终 JAR，分别填写加载器、游戏版本、更新说明及依赖。不要把另一加载器的 JAR 当作同一文件的附加安装包。
4. 提交审核后记录实际状态及平台回复；获批后再在 README、元数据和发布记录中加入真实 CurseForge 链接。

账号密码、验证码及 API 密钥不得提交到 Git。后续如配置自动上传，只通过项目所有者自行配置的 Actions secret 使用发布凭据，并限定到正确项目；没有凭据时不启用自动上传。
