# yztauth 认证扩展功能 设计

在已上线的 yztauth（Minecraft 1.20.1 Forge 登录认证 mod）之上新增一批功能。本设计是实施计划的依据。

## 目标与范围

**包含**（用户要求全选）：

**A 登录体验**
1. **A1 登录倒计时**：未登录提示的副标题显示剩余登录秒数。
2. **A2 剩余尝试次数**：登录失败时提示还可尝试几次（账号维度）。
3. **A3 密码强度提示**：注册后按规则给出弱/中/强。

**B 服务器管理**
4. **B1 审计日志**：登录/闸门失败写 `logs/yztauth-audit.log`，只记名字、IP、结果，**绝不记明文密码**。
5. **B2 登录通知管理员**：有玩家登录成功时，给在线管理员一条含 IP 的提示。
6. **B3 `/yztauth status`**：列出在线人数与当前未登录者。
7. **B4 隐藏未登录玩家**：未登录玩家不出现在**其他玩家**的 Tab 列表，登录后恢复。

**C 账号安全**
8. **C1 异地登录提醒**：与上次登录 IP 不同时提醒本人。
9. **C2 AFK 自动登出**：挂机超时自动登出；**默认关闭**（配置开关）。

**D 人情味**
10. **D1 首次进服广播**：未注册玩家进服时，向全服广播欢迎语。
11. **D2 欢迎语可自定义**：家长可在配置里覆盖欢迎标题/副标题文本。

**新子系统**
12. **留言系统**：私信 + 公开留言板（`public` 开关），登录时提醒未读，可删自己的；限量 + 超期自动清理。
13. **下线位置记录**：玩家登出时记录坐标/维度/时间到配置文件。
14. **位置查询与传送**：`/yztauth where <玩家>` 所有人可查；`/yztauth tp <玩家>` 由管理员在游戏内传送到记录位置（控制台无实体，不支持）。

**不包含**（本轮不做）：

- 全屏登录 GUI（用户约定的下一步）。

## 全局约束

- **密码安全**：任何日志不得出现明文密码；审计行只含 名字 / IP / 结果词。
- **裸指令**：不新增裸指令，全部挂在 `/yztauth` 下（避免与其它 mod 冲突）。
- **语言键**：`zh_cn.json` 与 `en_us.json` 键集合必须一致（`testLang` 强制）。
- **封锁规则不变**：未登录玩家仍只能执行 `/login`、`/register`、`/yztauth gate|login|register|help`；本批新增的 `mail`/`where`/`tp` **未登录时同样禁止**。
- **配置**：Forge SERVER 配置在 `world/serverconfig/yztauth-server.toml`；新增项必须给默认值且不破坏既有配置。
- 平台：Minecraft 1.20.1、Forge 47.4.0、JDK 17。

## 数据文件

均落在 `config/yztauth/`，读写沿用 `AccountStore` 的方式（原子写 + `.bak` 备份）。

| 文件 | 内容 |
|---|---|
| `users.json` | 账号库（现有） |
| `mail.json` | 留言：私信与公开条目 |
| `lastseen.json` | 每玩家最后下线位置（一人一条，覆盖式更新） |

## 各功能设计

### A1 登录倒计时

- 纯逻辑：`AuthManager.remainingSeconds(long joinedAt, long now, long limitMs)` → `max(0, ceil((limitMs-(now-joinedAt))/1000))`，返回秒。
- 闪烁重发（`WelcomeSync.resendTitle`）时，副标题拼接倒计时后缀。
- 语言键 `prompt_countdown`（含 `%s`）。
- 新副标题 = 原副标题 + `Lang.msg("prompt_countdown", secs)`。

### A2 剩余尝试次数

- 仅针对**登录**（账号维度）：失败后按 `Account.failedAttempts` 与 `maxLoginAttempts` 计算剩余。
- 纯逻辑：`AuthManager.remainingAttempts(int failed, int max)` → `max(0, max - failed)`。
- `RootCommand.doLogin` 的 BAD 分支：剩余 >0 时发 `login_bad_remaining`（含剩余数）；剩余为 0（下次即锁）时仍用原 `login_bad` 并进入锁定提示。
- 闸门走 IP 限流，剩余语义不同，保持既有 `login_rate_limited`，不改。

### A3 密码强度提示

- 纯逻辑：`data/PasswordStrength.of(String pw)` → `WEAK|MEDIUM|STRONG`。
  - 字符类计数：小写/大写/数字/其它符号（≥1 类即计）。
  - 长度 ≥8 且类数 ≥3 → STRONG；长度 ≥6 且类数 ≥2 → MEDIUM；否则 WEAK。
- `RootCommand.doRegister` 成功后追加 `password_strength` 提示（含强度词）。
- 语言键：`password_strength`（"%s" 占位）、`strength_weak/mid/strong` 三个词。

### B1 审计日志

- 新增 `audit/AuditLog`：可注入文件路径；`append(String line)` 追加一行，失败忽略（不抛、不影响登录流程）。
- 纯函数 `AuditLog.line(String timeIso, String name, String ip, String event)` → `"<timeIso> | <name> | <ip> | <event>"`（便于测试）。
- 时间用本地 `yyyy-MM-dd HH:mm:ss`。
- `event` 取值词：`LOGIN_FAIL`、`GATE_FAIL`、`LOGIN_LOCKED`、`RATE_LIMITED`。
- 触发点：`AuthManager.login` 的 BAD/LOCKED/RATE_LIMITED；`AuthManager.gateAttempt` 的 BAD/RATE_LIMITED。
- 配置 `auditLogEnabled`（默认 `true`）；路径固定 `logs/yztauth-audit.log`（相对游戏根目录）。

### B2 登录通知管理员

- 接线：`completeAuth` 后，遍历 `server.getPlayerList().getPlayers()`，对每个在线管理员（`Permissions.isAdmin`）且非本人的玩家，发 `admin_login_notice`（含名字与 IP）。
- 配置 `notifyAdminOnLogin`（默认 `true`）。
- 不做持久化。

### B3 `/yztauth status`

- 指令 `/yztauth status`，权限：管理员/控制台。
- 内容：在线人数、当前未登录者名字列表。
- 纯逻辑：`StatusCommand.render(String[] pendingNames, int online)` → 单行文本。
- 语言键 `status_line` = "在线 %s 人；未登录 %s 人：%s"。

### B4 隐藏未登录玩家（Tab）

**语义**：单向——未登录者不出现在**别人**的 Tab；未登录者自己仍能看到所有人（避免进服世界空荡）。

- 新增 `ui/TabHider`（全部为包发送，无持久状态）：
  - `hideFromOthers(ServerPlayer pending)`：给每个在线 `v≠pending` 发 `ClientboundPlayerInfoRemovePacket([pending.uuid])`。
  - `hidePendingFrom(ServerPlayer viewer)`：给 `viewer` 发 remove，覆盖所有当前 pending 的他人 UUID。
  - `reveal(ServerPlayer authed)`：给每个在线 `v≠authed` 发 `ClientboundPlayerInfoUpdatePacket.createPlayerInitializing([authed])`。
- 接线：
  - `onJoin`（未过闸/未登录分支）：`hideFromOthers(p)` + `hidePendingFrom(p)`。
  - `completeAuth`：`reveal(p)`。
- 已由字节码核实：`ClientboundPlayerInfoRemovePacket(List<UUID>)`、`ClientboundPlayerInfoUpdatePacket.createPlayerInitializing(Collection<ServerPlayer>)` 均存在。

### C1 异地登录提醒

- `Account` 新增字段 `lastIp`（String，可空）。
- `AuthManager.login` OK 分支：若 `a.lastIp != null && !a.lastIp.equals(ip)` → 给本人发 `login_new_ip`（含新 IP）；随后 `a.lastIp = ip`。
- 首次登录（`lastIp == null`）不提醒，只记录。
- 不写日志明文，IP 本身可入审计（已有）。

### C2 AFK 自动登出（默认关闭）

- 配置 `afkLogoutEnabled`（默认 **false**）、`afkLogoutSeconds`（默认 600）。
- 活动跟踪：`AuthManager` 维护 `Map<UUID, Long> lastActivityMs`；对**已认证**玩家，在 tick 中当位置或朝向变化超过阈值时刷新该时间；认证成功时初始化为当前时间。
- 超时判定（纯逻辑）：`AuthManager.afkExpired(long lastActivity, long now, long limitMs, boolean enabled)`。
- 触发：`onTick` 中若 `afkExpired` → `logout(p, AuthConfig.logoutMode())` 并给本人 `afk_logout` 提示。
- 玩家登出/断线时清理 `lastActivityMs` 条目，避免无限增长。
- 语义：默认关闭时该逻辑完全不生效。

### D1 首次进服广播

- 判定：`accountOf(name) == null` 视为首次。
- 纯逻辑（可测）：`WelcomeSync.firstJoinMessage(String name)` → `Lang.msg("first_join_broadcast", name)`。
- 接线：`onJoin` 且首次 → `server.getPlayerList().broadcastSystemMessage(msg, false)`。

### D2 欢迎语可自定义

- 配置 `welcomeTitleText`、`welcomeSubText`（String，默认空）。
- `WelcomeSync.welcomeTitle()/welcomeSub(name)`：配置非空 → `Component.literal(配置文本)`（副标题对 `%s` 做玩家名替换）；空 → 回退现有语言键。
- 保持颜色规则（金标题/黄副标题）。
- 纯逻辑：`WelcomeSync.resolveWelcomeTitle(String cfg)`、`resolveWelcomeSub(String cfg, String name)`。

### 留言系统

**数据模型** `data/Mail`：`id`(String)、`from`(小写名)、`to`(小写名；公开为 `""`)、`text`、`createdAt`(long)、`isPublic`(boolean)、`readAt`(long，0=未读；公开条目恒 0)。

**存储** `data/MailStore`（`config/yztauth/mail.json`）：

- `add(Mail)`、`all()`、`byId(id)`、`remove(id)`、`save()`/`load()`。
- `unreadFor(name)`：to==name 且 readAt==0 且非 public。
- `inboxFor(name)`：to==name 的私信（含已读）。
- `board()`：public 条目，按时间倒序。
- **限量**：加入私信前，若 `inboxFor(to).size() >= mailMaxPerPlayer` → 拒收。
- **超期**：`load()` 与每次 `save()` 前，丢弃 `createdAt` 早于 `now - mailExpireDays*86400_000` 的条目。
- `id`：6 位十六进制随机串（`Long.toHexString`），冲突则重取。

**纯逻辑（可测）**：`MailStore.canReceive(count, cap)`、`MailStore.expired(createdAt, now, days)`、`MailStore.canDelete(Mail, actorName, actorIsAdmin)`（私信：`from` 或 `to` 或 admin；公开：`from` 或 admin）。

**指令**（`command/MailCommand`，挂在 `/yztauth mail`）：

| 指令 | 说明 | 权限 |
|---|---|---|
| `send <玩家> <内容...>` | 发私信 | 所有人（未登录除外，受封锁拦截） |
| `post <内容...>` | 发公开 | 所有人 |
| `list` | 我的私信 + 公开板 | 所有人 |
| `board` | 只显示公开板 | 所有人 |
| `del <id>` | 删除（按上面的 canDelete） | 作者/收件人/管理员 |

- 校验：内容非空、收件人名 ≤16、限量检查；违规给对应失败消息。
- 提示：`completeAuth` 后若 `unreadFor(name) > 0` → 发 `mail_unread_notice`。

### 下线位置记录

**数据模型** `data/LastSeen`：`name`、`x/y/z`(double)、`yaw/pitch`(float)、`dimension`(String，如 `minecraft:overworld`)、`at`(long)。

**存储** `data/LastSeenStore`（`config/yztauth/lastseen.json`）：`put(name, LastSeen)`、`get(name)`、`save()`/`load()`。

**接线**：`AuthEvents.onLogout`（`PlayerLoggedOutEvent`）写一条（覆盖旧值）。

### 位置查询与传送

**指令**（`command/LocationCommand`，挂在 `/yztauth` 下）：

| 指令 | 说明 | 权限 |
|---|---|---|
| `where <玩家>` | 显示其**最后下线**维度与坐标、时间 | 所有人 |
| `tp <玩家>` | 传送**执行者本人**到该玩家的记录位置 | 执行者须为游戏内玩家且是管理员 |

- 纯逻辑：`LocationCommand.canTp(boolean executorIsPlayer, boolean executorIsAdmin)`（`isPlayer && isAdmin`）。
- 无记录 → `where_none`；控制台执行 tp（无实体）→ `tp_console` 失败提示。
- 语义：位置为「最后下线」快照；若目标此刻在线，仍显示其最近一次登出坐标，不做实时位置。
- 传送：`ServerPlayer.teleportTo(ServerLevel, x, y, z, yaw, pitch)`；维度按 `dimension` 字符串解析（找不到则回退当前维度）。

## 配置新增（`AuthConfig`）

| 键 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `mailMaxPerPlayer` | int | 20 | 每人私信上限 |
| `mailExpireDays` | int | 30 | 留言超期天数 |
| `auditLogEnabled` | boolean | true | 是否写审计日志 |
| `notifyAdminOnLogin` | boolean | true | 登录是否通知在线管理员 |
| `afkLogoutEnabled` | boolean | false | AFK 自动登出开关（默认关闭） |
| `afkLogoutSeconds` | int | 600 | AFK 判定秒数 |
| `welcomeTitleText` | String | ""（空=用语言键） | 自定义欢迎标题 |
| `welcomeSubText` | String | ""（空=用语言键） | 自定义欢迎副标题 |

## 语言键新增（中英同步）

`prompt_countdown`、`login_bad_remaining`、`password_strength`、`strength_weak`、`strength_mid`、`strength_strong`、`admin_login_notice`、`status_line`、`login_new_ip`、`afk_logout`、`first_join_broadcast`、`mail_sent`、`mail_posted`、`mail_empty`、`mail_no_recipient`、`mail_full`、`mail_none`、`mail_list_header`、`mail_board_header`、`mail_del_ok`、`mail_del_none`、`mail_del_denied`、`mail_unread_notice`、`where_result`、`where_none`、`tp_result`、`tp_console`。

## 权限模型

- `where`：所有人。
- `tp`：管理员或控制台发起，且执行者必须是游戏内玩家。
- `mail del`：私信=发件人/收件人/管理员；公开=作者/管理员。
- 复用现有 `perm.Permissions.isAdmin(ServerPlayer)`。

## 测试策略（`selftest`，沿用现有 Assert）

纯逻辑优先，全部可离线跑：

- `MailStore`：限量拒收、超期过滤、`canDelete` 三态、id 唯一、未读计数、公开板倒序。
- `LastSeenStore`：写入/覆盖/重载往返。
- `AuditLog.line`：格式与分隔符、不含明文（测试只传名字/IP/结果）。
- `WelcomeSync`：倒计时后缀拼接、首进广播消息键与参数、自定义欢迎语回退逻辑。
- `LocationCommand.canTp`/`where` 文本构建。
- `AuthConfig`：八个新默认值。
- `TabHider`：仅做「决策/目标集合」纯逻辑单测（谁该收到 remove）；发包本身靠人工走查。
- `AuthManager.remainingAttempts`、`PasswordStrength.of`、`StatusCommand.render`、`AuthManager.afkExpired`。

## 验收用例（加入 DEPLOY.md 走查表）

20. 倒计时：未登录提示副标题随闪烁显示"剩余 N 秒"，归零前被超时踢出。
21. 审计日志：输错密码后 `logs/yztauth-audit.log` 出现一行含名字/IP/`LOGIN_FAIL`，且**无明文**。
22. Tab 隐藏：A 未登录时，B 的 Tab 看不到 A；A 登录后出现。
23. 首进广播：新玩家首次进服，全服收到欢迎广播；老玩家进服不广播。
24. 留言：A 给离线 B 发私信，B 登录收到未读提醒，`list` 可见；`post` 公开所有人可见；`del` 权限正确；私信超 20 条被拒。
25. 位置：A 登出后 `/yztauth where A` 显示坐标；管理员 `/yztauth tp A` 传送成功；普通玩家 tp 被拒；控制台 tp 给出提示。
26. 剩余次数：登录连输错密码，提示剩余次数递减；到 0 后提示锁定。
27. 密码强度：注册时用 `abc`(弱)、`abcdef12`(中)、`Abcdef1!x`(强) 分别注册，提示强度正确。
28. 登录通知管理员：管理员在线时，有玩家登录，管理员收到含 IP 提示；`notifyAdminOnLogin=false` 时不发。
29. `/yztauth status`：返回在线人数与未登录名单；普通玩家被拒。
30. 异地登录提醒：用不同 IP 再次登录，本人收到新 IP 提示；首次登录不提示。
31. AFK（默认关闭）：`afkLogoutEnabled=false` 时挂机不登出；置 true 且 `afkLogoutSeconds` 调小后，挂机超时自动登出。
32. 自定义欢迎语：`welcomeTitleText`/`welcomeSubText` 非空时，登录显示自定义文案且仍为金/黄配色。
