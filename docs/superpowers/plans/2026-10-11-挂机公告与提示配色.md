# 挂机公告 + 提示文本配色审查 实施计划（2026-10-11）

> **For agentic workers:** 任务逐条实现，纯逻辑走自测门禁（`gradle build selfTest`）。

**Goal:** （1）新增挂机检测——玩家超过阈值无操作时全服广播随机「睡着了」文案，重新操作时广播随机「回来了」文案并给本人放提示音 + 私人欢迎语；（2）审查并优化 mod 内用户可见提示文本的准确性与配色。

**Spec/Plan:** 本文件即 plan（沿用 `yztauth` 既有 SDD 分层与自测框架）。

## Global Constraints

- 不改动既有封锁规则、审计规则。
- 语言键中英同步（`testLang` 强制 zh_cn 与 en_us 键集合一致）。
- 配置只新增键并给默认值；`testConfig` 覆盖每个新默认值。
- 不新增裸指令（本功能无指令入口）。
- 绝不记录明文密码。
- 构建门禁：`gradle selfTest` 与 `gradle build` 全绿。改动前基线 **1270 通过 / 0 失败**。

## Task 2: AfkBroadcast 纯逻辑与消息

**Files:** `broadcast/AfkBroadcast.java`（新建）、`selftest/SelfTestMain.java`

**Interfaces（Produces）:**
- `AfkBroadcast.shouldEnterAway(boolean away, long idleMs, long limitMs):boolean`
- `AfkBroadcast.shouldReturn(boolean away, boolean active):boolean`
- `AfkBroadcast.pickVariant(int size, Random r):int`
- `AfkBroadcast.awayKey(int idx):String` / `backKey(int idx):String`
- `AfkBroadcast.awayMessage(String name, int idx):MutableComponent`（名字金色加粗 + 文案灰色斜体）
- `AfkBroadcast.backMessage(String name, int idx):MutableComponent`（名字绿色加粗 + 文案黄色）
- `AfkBroadcast.welcomeMessage():MutableComponent`（绿色）
- `AfkBroadcast.tick(ServerPlayer p, boolean active, long idleMs, long limitMs, boolean enabled):void`
- `AfkBroadcast.forget(UUID)` / `clearAll()`

- 自测：状态机边界（差 1ms / 到点 / 已挂机不重复 / 有操作才返回）、随机序号取值、键声明、消息各段颜色。

## Task 3: 事件接入与提示音

**Files:** `auth/AuthManager.java`、`ui/Sounds.java`

- `onAuthenticatedTick`：把既有 `viewChanged` 结果作为 `active`，复用活动时间戳算出 `idleMs`，调用 `AfkBroadcast.tick`；AFK 公告与 AFK 自动登出相互独立（后者阈值更长且默认关）。
- `onLeave` / `logout` / `completeAuth` / `load`：清除玩家标记，避免刚登录误报「回来了」。
- `Sounds.welcomeBack`：`entity.experience_orb.pickup`。
