# yztauth 认证扩展功能 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在已上线的 yztauth 上落地 14 项新功能（登录体验 / 服务器管理 / 账号安全 / 人情味 / 留言 / 位置），并把 mod 打包成带图标与完整元数据的"产品"。

**Architecture:** 沿用现有分层：`data`（模型+存储）、`command`（Brigadier 指令）、`ui`（提示与发包）、`auth`（状态机）、`config`（Forge 配置）、`audit`（新建）。新纯逻辑集中在可离线单测的静态函数里；触网/落盘部分靠手工走查。

**Tech Stack:** Java 17、Minecraft 1.20.1、Forge 47.4.0、Brigadier、Gson、ForgeConfigSpec、自建 `selftest` 测试框架。

**Spec:** `docs/superpowers/specs/2026-10-09-认证扩展功能-design.md`

## Global Constraints

- **绝不记录明文密码**：任何日志/审计/提示不得含明文；审计行只含 时间 / 名字 / IP / 结果词。
- **不新增裸指令**：全部挂在 `/yztauth` 下。
- **语言键中英同步**：`zh_cn.json` 与 `en_us.json` 键集合必须一致（`testLang` 强制）。
- **封锁规则不变**：未登录玩家仍只放行 `/login`、`/register`、`/yztauth gate|login|register|help`；`mail`/`where`/`tp`/`status` 未登录时一律拦。
- **配置向后兼容**：只新增键并给默认值；`testConfig` 覆盖每个新默认值。
- 构建：`gradle selfTest` 与 `gradle build --no-daemon --console=plain -Dfg.check.certs=false`（gradle 不在 PATH，需先 export 见 DEPLOY.md）。产物 `build/libs/yztauth-1.0.0.jar`。
- 当前自测基线：**179 通过 / 0 失败**。每个任务结束时该数只增不减。

## Review Focus

- **零值/边界**：`remainingAttempts` 在 `failed==max` 时应为 0；`expired` 在恰好到期日应为"已过期"还是"未过期"需明确（取 `>=`）；`afkExpired` 在 `enabled=false` 时永远 false。
- **并发进服（Tab 隐藏）**：A、B 同时未登录时互相不可见；A 登录后 B 应看到 A；退服重连不应残留隐藏。
- **留言超期与限量交互**：先判超期再判限量，避免把已过期条目算进配额。
- **审计不泄密**：任何 event 分支都不得把 `password` 拼进 line。
- **离线位置**：目标离线时 `tp` 要能落到其记录维度；维度解析失败要回退而不是崩溃。
- **配置文件损坏**：`mail.json`/`lastseen.json` 损坏时应像 `AccountStore` 一样抛清晰异常或被跳过，不得静默丢数据。

```java
public final class PasswordStrength {
    private PasswordStrength() {}
    public enum Level { WEAK, MEDIUM, STRONG }
    public static Level of(String pw) {
        if (pw == null) return Level.WEAK;
        int lower = 0, upper = 0, digit = 0, other = 0;
        for (int i = 0; i < pw.length(); i++) {
            char c = pw.charAt(i);
            if (Character.isLowerCase(c)) lower = 1;
            else if (Character.isUpperCase(c)) upper = 1;
            else if (Character.isDigit(c)) digit = 1;
            else other = 1;
        }
        int classes = lower + upper + digit + other;
        if (pw.length() >= 8 && classes >= 3) return Level.STRONG;
        if (pw.length() >= 6 && classes >= 2) return Level.MEDIUM;
        return Level.WEAK;
    }
}
```

```java
public final class AuditLog {
    private final Path file;
    public AuditLog(Path file) { this.file = file; }
    public void append(String line) {
        try {
            Path parent = file.getParent();
            if (parent != null) Files.createDirectories(parent);
            Files.writeString(file, line + System.lineSeparator(), StandardCharsets.UTF_8,
                    StandardOpenOption.CREATE, StandardOpenOption.APPEND);
        } catch (IOException ignored) { /* 审计失败不影响登录 */ }
    }
    public static String line(String timeIso, String name, String ip, String event) {
        return String.join(" | ", timeIso, name, ip, event);
    }
    public static String nowIso() {
        return java.time.LocalDateTime.now()
                .format(java.time.format.DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss"));
    }
}
```
