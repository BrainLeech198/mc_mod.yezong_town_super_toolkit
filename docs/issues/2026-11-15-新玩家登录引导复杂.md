# [已修复] 新玩家登录引导不够直观

- 影响：不熟悉 Minecraft 命令、年龄较小或首次进入服务器的玩家可能不清楚需要注册还是登录，输错后也可能不知道如何继续。
- 前置条件：玩家首次进服或需要重新认证。
- 复现步骤：进入服务器；观察聊天栏中的 GUI/命令双入口；在自动打开的铁砧框提交错误密码。
- 预期结果：根据账号状态明确显示“设置密码”或“登录”；只提供一个可操作入口；提交失败后能直接修改并重试。
- 实际结果（修复前）：聊天栏同时显示 GUI 与命令选项；铁砧标题只有操作说明；提交错误后窗口关闭，玩家需要自行发现并点击重开入口。
- 根因/调用链：`AuthEvents` → `AuthManager.onJoin` → `WelcomeSync.promptLogin` / `promptGate` → `AuthGui` → `AnvilInput`；成功与失败共用一次性输入回调，失败后都会关闭窗口。
- 修复范围：新账号显示设密提示、最低长度和记住密码的说明；已有账号显示登录提示及忘记密码求助方式；聊天栏只保留一个重开按钮；使用可重试输入流程，错误后保留窗口并清空输入；账号密码、闸门、限流、持久化规则不变。
- 验证：`gradle jar --no-daemon` 编译与重映射成功；中英文 JSON 解析通过；未运行自测或游戏内试玩。
- 状态：已修复
- 修复版本：`1.1.1`
