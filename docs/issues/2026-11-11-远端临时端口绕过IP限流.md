# [已修复] 远端临时端口绕过 IP 限流

- 影响：登录与全服闸门的按 IP 限流，以及登录 IP 变更提醒和审计地址。
- 前置条件：玩家通过常规 TCP 连接进入服务器，并从同一公网 IP 重连/重复尝试。
- 复现步骤：从同一客户端 IP 多次建立连接，观察远端地址字符串中的端口不同；重复失败登录时也会更换连接。
- 预期结果：同一主机的连接共享限流桶；IP 变化只在主机地址变化时提示。
- 实际结果（修复前）：`SocketAddress.toString()` 包含端口，例如 `203.0.113.8:53124`；新连接源端口变化会形成新 key，并造成错误的新 IP 提示。
- 根因/调用链：`AuthManager.resolveIp` → `login` / `gateAttempt` 的 `RateLimiter`，并用于审计、管理员通知及 `lastIp`。
- 修复范围：`InetSocketAddress` 只取主机地址，其他非空 SocketAddress 保留既有字符串回退；不改变代理头获取方式。
- 验证：`gradle jar --no-daemon` 编译与重映射成功；未运行自测或游戏内连接验证。
- 状态：已修复
- 修复版本：`1.1.0`
