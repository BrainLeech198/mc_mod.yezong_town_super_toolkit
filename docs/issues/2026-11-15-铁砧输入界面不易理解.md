# [已修复] 铁砧输入位置不易发现

- 影响：不熟悉 Minecraft 的玩家不清楚要点击哪里输入，以及如何提交，容易卡在密码、留言等输入步骤。
- 前置条件：打开任意由 `AnvilInput` 管理的输入界面。
- 复现步骤：打开铁砧输入；观察窗口中的纸张输入槽和右侧结果物品；尝试判断输入/提交位置。
- 预期结果：界面有清楚的文字指引，能区分输入位置、提交按钮和取消方式。
- 实际结果（修复前）：通用输入位置没有提示名；“提交”只标注动作名；部分输入流程没有说明如何开始输入。
- 根因/调用链：认证、账户、邮件、广播和管理员验密最终都会经过 `AnvilInput.open`；原版铁砧界面无法由服务端 Mod 添加自定义控件标签，但可利用聊天提示与物品悬浮说明。
- 修复范围：每次打开铁砧时显示统一操作提示；左侧纸张与右侧绿色提交物品增加编号悬浮说明；不改提交、取消或各输入流程的关闭行为；中英文均有服务端兜底。
- 验证：中英文 JSON 均可解析；`gradle jar --no-daemon --console=plain -Dfg.check.certs=false` 成功，Forge `reobfJar` 完成；JAR 内 `mods.toml` 与 manifest 版本均为 `1.1.5`；实际客户端显示仍需试玩确认。
- 状态：已修复并打包
- 修复版本：`1.1.5`
