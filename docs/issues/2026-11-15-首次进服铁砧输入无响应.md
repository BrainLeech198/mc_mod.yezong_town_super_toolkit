# [已修复] 首次进服铁砧输入框无法接收文字

- 影响：玩家首次进入服务器时，自动弹出的认证铁砧偶发无法输入密码，阻断注册或登录。
- 前置条件：玩家进服后由服务器自动打开认证铁砧。
- 复现步骤：首次进入服务器；在自动打开的铁砧输入框内点击占位纸并尝试输入。
- 预期结果：客户端完成进服界面初始化后打开认证铁砧，输入框可以接收键盘输入。
- 实际结果（修复前）：首次打开时输入框偶发无法输入；再次打开可能恢复正常。
- 根因/调用链：`AuthEvents.onLogin` → `AuthManager.onJoin` → `server.execute` → `AuthGui.openFor` → `AnvilInput.open`。`server.execute` 在服务器主线程可能立即执行，并不保证延后一 tick，导致自动打开与客户端进服界面初始化竞态。
- 修复范围：改用 `Defer.nextTick` 明确将自动打开排到下一服务端 tick，并在执行时再次确认玩家仍处于待认证状态。手动重开入口、认证逻辑和密码规则不变。
- 验证：`gradle jar --no-daemon --console=plain -Dfg.check.certs=false` 成功，Forge `reobfJar` 完成；JAR 内 `mods.toml` 与 manifest 版本均为 `1.1.3`；未进行真实服务器首次进服试玩。
- 状态：已修复并打包
- 修复版本：`1.1.3`
