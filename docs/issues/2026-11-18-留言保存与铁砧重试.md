# 留言保存状态不一致与铁砧提交失败后关闭

- 复现条件：留言 JSON 无法写入，或私信/管理员公告的铁砧输入触发内容校验、容量或持久化错误。
- 影响：写入/删除/已读操作可能只改变当前服务器内存状态，重启后恢复旧数据；称号修改也会产生同样的不一致；部分铁砧流程在发送失败时关闭窗口，玩家需要重新进入并重输内容。
- 根因/调用链：`MailCommand`、`MailPanel` 和称号操作先修改内存数据，再调用 `save()`，但失败路径没有回滚；`InputPrompt.choose` 把铁砧提交包装成一次性回调，导致失败结果也关闭界面。
- 修复边界：留言和称号保存失败时恢复对应操作前的状态；私信与公告铁砧使用可返回状态的输入流程，只有提交成功才关闭。命令格式、权限、JSON 格式和成功流程不变。
- 验证：Gradle `jar` / Forge `reobfJar` 构建通过；未在 Minecraft 客户端模拟磁盘写入失败或实际输入操作，需在服务器环境验收。
- 修复版本：`1.3.1`
