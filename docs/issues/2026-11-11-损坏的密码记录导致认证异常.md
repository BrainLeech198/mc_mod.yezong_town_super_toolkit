# [已修复] 损坏的密码记录导致认证异常

- 影响：账号库或闸门记录中的 PBKDF2 字段缺失、Base64 非法或迭代次数越界时，登录/过闸可能抛异常；错误发生在服务器命令调用路径。
- 前置条件：`config/yzt_super/users.json` 中对应记录被手工改坏、部分写入或来自不兼容数据；闸门记录同理。
- 复现步骤：将某条 `pbkdf2-sha256` 记录的 `salt` 改为非法 Base64（例如 `!`），玩家发起登录；或把闸门字段改为无效值后过闸。
- 预期结果：该凭据校验失败，认证逻辑继续运行，不因记录字段异常抛出解码/参数异常。
- 实际结果（修复前）：Base64 解码或 PBKDF2 参数异常可从认证调用路径逃出。
- 根因/调用链：`/login` / 闸门 GUI → `RootCommand` → `AuthManager.login` / `GateManager.verify` → 直接解码持久化字段并派生摘要。
- 修复范围：统一安全校验 Base64 编码记录；只识别已支持的算法；PBKDF2 参数缺失、非法或超出支持上限时按失败处理。没有变更 JSON 格式或合法账号行为。
- 验证：`gradle jar --no-daemon` 编译与重映射成功；未运行自测或游戏内异常数据验证。
- 状态：已修复
- 修复版本：`1.1.0`
