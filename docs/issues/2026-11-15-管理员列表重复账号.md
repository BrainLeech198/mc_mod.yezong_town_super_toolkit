# [已修复] 管理员列表重复显示同一账号

- 影响：账号库中同一玩家名存在大小写不同的键时，管理员面板可能把同一在线玩家显示多次。
- 前置条件：管理员打开 `/yzts admin` 面板，账号库存在大小写不同但忽略大小写相同的键。
- 复现步骤：在账号库加入 `Steve` 与 `steve` 两个键；管理员打开账号列表。
- 预期结果：同一玩家名只显示一条。
- 实际结果（修复前）：面板直接列出原始账号键；两条键都通过不区分大小写的在线匹配显示成同一在线档案名。
- 根因/调用链：`AdminPanel.PanelMenu.refresh` → `StoreHolder.get().names()`；账号库保留原始 JSON 键大小写，而面板按不区分大小写查在线玩家，展示时两条键会映射到相同档案名。
- 修复范围：只在管理员面板展示列表按不区分大小写去重，优先保留小写规范键；不改账号库文件和认证逻辑。
- 验证：`gradle jar --no-daemon --console=plain -Dfg.check.certs=false` 成功，Forge `reobfJar` 完成；JAR 内 `mods.toml` 与 manifest 版本均为 `1.1.4`；未进行服务器内 GUI 试玩。
- 状态：已修复并打包
