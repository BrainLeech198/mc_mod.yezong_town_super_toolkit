# 认证与留言数据边界问题

- 复现条件：账号库所在目录不可写/磁盘写入失败；或 `mail.json` 中混有单条字段损坏记录、收件人大小写与当前账号键不同的历史记录。
- 影响：注册可能只存在于内存却提示成功并放行；改密、邮箱、管理员账号操作或闸门状态可能出现内存与磁盘不一致；损坏的单条留言可能让整库加载失败；大小写不同的留言可能未出现在收件箱。
- 根因/调用链：`AuthManager.register` 写入内存后调用吞掉异常的 `persist()` 并继续 `completeAuth`；其他账号/闸门变更先改对象再落盘；`MailStore.load` 未隔离单条反序列化错误，收件箱按原始大小写精确匹配。
- 修复边界：认证/管理数据写盘失败时回滚对应字段或账号，不将注册错误当作成功；留言加载时校验并跳过无效单条、归一化发送人/收件人，查询也按不区分大小写匹配。JSON 格式、命令和权限保持兼容。
- 验证：Gradle `jar` / Forge `reobfJar` 构建通过；中英文新增提示键已核对。未注入文件系统故障或在运行服务器中构造损坏数据验证。
- 修复版本：`1.3.4`
