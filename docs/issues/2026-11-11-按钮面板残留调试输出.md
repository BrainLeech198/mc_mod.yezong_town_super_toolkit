# [已修复] 按钮面板残留调试输出

- 影响：使用服务端按钮面板的玩家会在聊天栏收到调试文本；菜单打开时还会安排延迟检查任务。
- 前置条件：打开任何使用 `ButtonPanel` 的箱式菜单，或点击/关闭菜单。
- 复现步骤：打开邮箱、账户或管理面板，观察聊天栏；点击任一按钮或关闭界面。
- 预期结果：只显示功能本身的提示，不显示诊断信息。
- 实际结果（修复前）：打开、点击、槽位检查和关闭都会发送 `[yzt-dbg]`；每次打开另排一个 40 tick 任务。
- 根因/调用链：各面板 → `ButtonPanel.open` / `ButtonPanel.Menu.clicked` → 临时调试探针。
- 修复范围：移除探针消息、延迟探针任务和仅供探针使用的覆写；保留箱式菜单、按钮动作和下一 tick 调度。
- 验证：静态搜索确认生产源码不再含 `TEMP-DEBUG` 或 `[yzt-dbg]`；`gradle jar --no-daemon` 编译与重映射成功；未运行游戏内验证。
- 状态：已修复
- 修复版本：`1.1.0`
