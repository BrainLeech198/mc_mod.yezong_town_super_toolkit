# 儿童登录注册指引不够直观

- 复现条件：第一次加入服务器或忘记密码的玩家需要通过自动弹出的铁砧窗口认证。
- 影响：玩家可能不清楚首次加入要创建密码、窗口顶部哪里输入、右侧按钮做什么，或提交失败后如何继续。
- 根因/调用链：`AuthManager.onJoin` → `AuthGui.openFor/openLoginOrRegister` 自动区分注册/登录并打开铁砧 → `RootCommand.doRegister/doLogin` 输出结果 → `AnvilInput.Response.retry` 清空输入但没有后续操作说明；聊天入口文案为“重新输入”，对首次加入者不够准确。
- 修复边界：只调整中英文提示、铁砧操作说明及失败后的下一步提示；保留自动区分账号、密码验证/注册、失败次数、超时和锁定规则，不改认证数据格式与权限。
- 验证：Gradle `jar` / Forge `reobfJar` 构建通过，语言 JSON 可解析且新提示键在中英文文件中齐全；未在 Minecraft 客户端与儿童玩家实测，文案仍需实际可用性反馈。
- 修复版本：`1.3.3`
