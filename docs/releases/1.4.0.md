# 野粽乡超级工具箱 v1.4.0

日期：2026-11-19。新增 Minecraft 1.20.1 的 Fabric 服务端版本，保留 Forge 47.4.0 基线，并补齐认证、存储、菜单与权限修复。整合来自 [PR #1](https://github.com/BrainLeech198/mc_mod.yezong_town_super_toolkit/pull/1)。

## 安装包

| 文件 | 服务端要求 |
|---|---|
| `yzt_super-1.4.0-mc1.20.1-forge.jar` | Minecraft 1.20.1、Forge 47.4.0、Java 17 |
| `yzt_super-1.4.0-mc1.20.1-fabric.jar` | Minecraft 1.20.1、Fabric Loader 0.20.1、Fabric API 0.92.12+1.20.1、Forge Config API Port 8.0.3（Fabric 版）、Java 17 |

每次只放入与服务端加载器对应的一个工具箱包；升级前移除旧工具箱 JAR。玩家使用原版 1.20.1 客户端，无需安装本 Mod。NeoForge 与其他 Minecraft 版本尚未交付。

发行入口：[v1.4.0 Release](https://github.com/BrainLeech198/mc_mod.yezong_town_super_toolkit/releases/tag/v1.4.0)。最终附件的完整 SHA-256、源提交和发行构建链接随 Release 的校验文件及来源记录提供。

## 本次变化

- 新增 Fabric 独立装配、事件与命令封锁、世界配置及称号适配；按加载器区分 JAR。
- 固定 Gradle Wrapper，移除机器专属 JDK 路径；增加公共 Java 模块、最终包检查和双平台远程构建。
- 登录成功及错密计数先保存再提交状态，写盘失败继续保持未认证限制。
- 五库整库加载失败后阻止后续覆盖；完善位置、风险、迁移、留言和称号的失败回滚。
- 修复铁砧右槽按钮、会话清理、命令闸门检查、称号更新及 LuckPerms 三态权限判断。

## 验证与边界

发行附件使用对应源提交的 GitHub 构建产物。Forge 执行 `clean selfTest build`（JDK 17），Fabric 执行 `clean build`（JDK 25，输出 Java 17 字节码）；任务和来源记录见 [构建工作流](../../.github/workflows/build.yml)。完整结果以该提交工作流为准。

协作者在改版前的同一游戏代码上报告 Forge 1,482 项自测通过，并完成双平台独立服、原版客户端、登录与留言、权限、模式恢复和写盘故障等验证，详见[原始平台验收记录](../平台验收.md)。发布准备只调整版本、发行文档及工作流；此运行证据不等于对 1.4.0 最终附件重新完成全部真人操作。

实际公网代理、第三方 Mod 冲突、多人 AFK、`restoreLastGameMode=false`、45 人以上管理分页和指南书逐页显示等仍需部署方实测。

## 升级与回滚

1. 停服并备份世界、`config/`、世界内 `serverconfig/` 与旧 `mods/`，保持同一时点快照。
2. 移除旧工具箱包，选择相应加载器的 1.4.0 JAR；Fabric 安装上述必需依赖。
3. 五类 JSON 的字段与路径保持兼容，无需格式迁移；切换加载器先在备份副本测试，不要同时写同一份数据。
4. 回滚时停服，恢复原加载器、Mod 及同一时点配置/数据快照，避免新旧进程并行写库。
