# Development provenance / 开发来源

The maintainers confirm that this project's source code was primarily generated using AI tools, including Codex. AI tools also contributed documentation, translations, release text and the vector toolbox icon. Human maintainers define requirements, review changes and maintain the repository; their involvement does not make the code primarily human-written.

The toolbox icon is an AI-authored geometric vector illustration, not an in-game screenshot. Its editable source and renderer are in `assets/branding/icon.svg` and `scripts/render_icon.py`. It does not show or promise an in-game item.

No generative AI service is required to run the mod. This statement describes the development process; it is not an independent security review or a guarantee of correctness. Build checks and game verification have separate evidence in [platform validation](docs/平台验收.md) and [release records](docs/releases/1.4.0.md).

Maintainers/contributors include [BrainLeech198](https://github.com/BrainLeech198) and [TYE623](https://github.com/TYE623). Commit authorship records who submitted a change, not who manually wrote every line. The project's current licensing notice is [All Rights Reserved](LICENSE); access to source does not imply an open-source licence. Third-party components retain their own licences.
